# Data Model: React Astro Project Skeleton

## Overview

The starter site has no persisted or visitor-submitted data. Its first page is generated from
authored source content, with clearly marked placeholders until the organization approves public
details.

## Static Page Content

| Content field | Initial value | Validation |
|---------------|---------------|------------|
| Organization name | Clearly marked placeholder | Must not imply an unapproved public name. |
| Purpose | Clearly marked placeholder | Must not state unapproved charity claims as facts. |
| Activities | Clearly marked placeholder | Must not state unapproved activities as facts. |
| Contact route | Clearly marked placeholder or omitted | Must not expose unapproved contact details. |
| Last reviewed date | Clearly marked placeholder or omitted | Must not imply a review date that has not occurred. |

## Relationships and lifecycle

- The page is the only initial content unit; there are no entity relationships or identities.
- Placeholder content remains in place until an authorized representative supplies approved
  information.
- This feature introduces no persistence, user accounts, or visitor-submitted data.
